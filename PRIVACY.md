# Política de Privacidade — LOLLIFLIX PRO

**Última atualização:** 24/09/2026

O LOLLIFLIX PRO é um aplicativo reprodutor de mídia (player) focado em Doramas, Novelas e
Novelas Turcas, que também dá acesso ao catálogo completo do provedor/painel IPTV do
usuário (padrão Xtream Codes).

## Dados usados
- **Usuário e senha do provedor IPTV:** armazenados **somente no aparelho** para login automático. Não enviamos a nenhum servidor nosso.
- **Preferências locais:** favoritos, histórico e configurações ficam apenas no aparelho.

## Dados que NÃO coletamos
- Não coletamos dados pessoais para nossos servidores, não usamos rastreadores de anúncios e não compartilhamos dados com terceiros.

## Serviços de terceiros
- **Provedor IPTV:** o app conecta diretamente ao painel configurado pelo usuário. O LOLLIFLIX PRO não hospeda nem controla nenhum conteúdo.
- **TMDB:** usamos a API do The Movie Database apenas para organização (capas, sinopses, backdrops e notas). Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.
